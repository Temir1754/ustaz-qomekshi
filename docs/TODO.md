# Ustaz Qömekşi — что осталось сделать

## Сделано
- [x] Загрузка КСП/КТП в облако — Яндекс.Диск и Dropbox (`src/cloud_upload.py`), по личному токену учителя.
- [x] **Просмотр/редактирование сгенерированного документа** — кнопки `ksp:view`/`ksp:edit` и
  `ktp:view`/`ktp:edit` (`src/bot.py`) теперь показывают структурированный текст (цель + 4 этапа
  для КСП, разделы/уроки для КТП) и дают точечно отредактировать поле (этап→поле или урок),
  после чего `.docx` перестраивается из тех же данных (`KSP_CONTENT`/`KTP_CONTENT`,
  `docx_export.resolve_ksp_content()`). Заодно исправлен баг: кнопки КТП раньше вели на
  `ksp:view`/`ksp:edit` (чужой callback) вместо `ktp:view`/`ktp:edit`.

## Не реализовано (заглушки)

- [ ] **Google Drive / OneDrive / Mail.ru** — `upload_to_cloud()` поднимает `NotImplementedError`.
  Требуют OAuth-приложения у провайдера (client_id/secret, redirect URI) — регистрация приложения
  делается вне Claude Code, потом можно писать обмен кода на токен и сам аплоад.
- [ ] **Реальное расписание с Kundelik.kz** — `src/kundelik_api.py:build_today_lines()` всегда
  возвращает `None`. Схема JSON-ответа `/v2/schedules/` не разобрана — нужен реальный ответ
  (залогирован в `build_today_lines_or_log()`), чтобы дописать парсинг.
- [ ] **Генерация теста** — кнопка `quick:test` (`src/bot.py`) — заглушка (`quick_test_stub`).
